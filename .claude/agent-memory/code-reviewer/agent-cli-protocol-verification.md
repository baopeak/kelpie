Chat adapters (app/src/chat/*-adapter.ts) encode wire shapes of external CLIs; verify them against the installed binaries rather than trusting comments.

- Codex: `codex app-server generate-json-schema --out <scratchpad dir>` then read `codex_app_server_protocol.v2.schemas.json` (definitions: TurnStartParams, ThreadShellCommandParams, ReviewTarget, SandboxPolicy, UserInput incl. `skill`). Fast, offline.
- Claude Code (native claude.exe, ~300 MB Bun bundle at ~/.local/bin): grep is too slow; use Python `mmap` + `find(b'q.request.subtype==="set_model"')` to read control handlers. set_model replies `{model}`, set_permission_mode replies `{mode}`.
- Live probe (no API call): pipe one `{"type":"control_request","request_id":"x","request":{"subtype":"initialize"}}` into `claude -p --input-format stream-json --output-format stream-json --verbose` with `env -u CLAUDE_CODE_ENTRYPOINT -u CLAUDECODE`. On 2.1.308 (2026-10-23) initialize answered commands/models/current_permission_mode WITHOUT the sdk-ts entrypoint.
- Sending `initialize` twice to one claude process (new ChatController re-attach) answers success both times (2.1.308).
- Codex 0.163 facts: `thread/shellCommand` runs UNSANDBOXED with full access; Thread{Start,Resume}Response.sandbox is a full SandboxPolicy (networkAccess, writableRoots) and approvalPolicy may be `untrusted`/granular — coarse presets lose those.
- Schema dumps go to the scratchpad; C: was 100% full on 2026-10-23, delete dumps after use.
- ACP (generic adapter; third-party CLIs usually NOT installed on this box): curl `raw.githubusercontent.com/agentclientprotocol/agent-client-protocol/main/schema/v1/schema.json` into scratchpad, read `$defs` (Implementation needs name+version; CreateElicitationRequest/Response; ErrorCode auth -32000, not-found -32002). Strictness of TS agents: `gh api repos/agentclientprotocol/typescript-sdk/contents/src/v1/schema/zod.gen.ts -H "Accept: application/vnd.github.raw"` (`defaultOnError` = lenient). Docs pages accept a `.md` suffix (protocol/v1/elicitation.md). `scripts/e2e/fake_acp_agent.py` is the local stand-in agent.
- `@path` quoting per TUI (checked 2026-10-24): Gemini CLI `packages/core/src/utils/paths.ts` escapePath/unescapePath — Windows: double-quote when name matches `[\s&()[\]{}^=;!'+,`~%$@#]`; POSIX/macOS: backslash-escape, quotes NOT stripped (so `@"a b"` fails on macOS). Claude CLI accepts `@"path with spaces"`. Codex TUI does not expand `@` (model reads the text). Fetch raw files from GitHub via WebFetch.
- `CLAUDE_CODE_ENTRYPOINT=sdk-ts` changes client attribution (claude_code_sdk / sdk-typescript UA) and drops a tool from the toolset — flag any use of it.

- Claude task events (2.1.310, 2026-10-25): mmap-find `subtype:"task_started"` etc. Emitter sets `is_backgrounded` only if the task object has `isBackgrounded` (else omitted); Claude's own foreground test is `"isBackgrounded" in e && e.isBackgrounded===false`. Terminal status emits task_updated{patch.status} then task_notification. Local agents can carry `awaited:true` (awaitedByCaller).
- Checkpoint TurnRecord.at = max(ticker-seen turn end, snapshot finish) (checkpoints.rs ~811), often >1 s after the UI's `result`; queued chat messages are sent before it. Attribute turns by `started`, not `at`.
- Agent config files (2026-10-25): claude.exe saves `~/.claude.json` via proper-lockfile (`${file}.lock` mkdir lock; "Failed to save config with lock") re-reading the base under lock — any external writer must take that lock. Codex 0.163 `RawMcpServerConfig` has `env_vars`, `env_http_headers`, `bearer_token_env_var`, `cwd`, `required` (so "Codex can't reference env" is false). Find codex.exe by globbing `%APPDATA%\npm\*\@openai\codex*\**\codex.exe` inside a Python file (Bash text naming node_modules is blocked). Run mmap greps with `python -X utf8`. 2.1.310 details: lock is `vl(y,{lockfilePath:\`${y}.lock\`})` on the UNRESOLVED path (stale 10 s default, update 5 s, ELOCKED backoff [200..4000] ms); `${VAR}` expansion applies to user/local/project MCP scopes (`ilt` expandVars default true), only managed is unexpanded. Useful needles: `lockRetrySignal`, `expandVars:`, `function S_(`.

- Claude stream-json stdin (2.1.310, 2026-10-25, live probes with only `initialize`): a lone `\r` is NOT a line break (the joined line fails "Error parsing streaming input line" and the process EXITS 1 — any unparsable line kills a chat); extra top-level keys are ignored, so `{"type":"control_request",...,"id":"r9","result":0}` is still run; a `control_response` for an unknown request_id is ignored silently. Use this when judging any "is this line only an answer?" filter: dispatch is by `type` alone.

- Agent-to-client request kinds (2026-10-25): Claude 2.1.310 sendRequest subtypes `can_use_tool`, `elicitation`, `hook_callback`, `mcp_message`, `oauth_token_refresh`, `request_user_dialog` (mmap regex `type:"control_request",request_id:[^,]{1,40},request:\{subtype:"([a-z_]+)"` mixes both directions; `sendRequest({subtype:` is CLI->client). Codex 0.163 ServerRequest (`ServerRequest.json` oneOf method enums): commandExecution/fileChange/permissions `requestApproval`, `item/tool/requestUserInput`, `mcpServer/elicitation/request`, `item/tool/call`, `account/chatgptAuthTokens/refresh`, `attestation/generate`, `applyPatchApproval`, `execCommandApproval`. Token-refresh kinds must never be remote-answerable.
